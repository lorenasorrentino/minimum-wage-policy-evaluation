# Minimum Wages and Unemployment

## Overview

This project examines the relationship between statutory minimum wages and unemployment rates in European countries using panel data from 2013 to 2025.

## Research Question

Do increases in minimum wages lead to higher unemployment?

## Data

The analysis combines minimum wage data with macroeconomic indicators from Eurostat, covering 26 countries over multiple years.

## Methodology

The analysis estimates pooled OLS and fixed effects models, with country and year fixed effects and clustered standard errors.

## Key Findings

Once country and year fixed effects are included, there is no robust evidence that minimum wage increases significantly affect unemployment rates.
